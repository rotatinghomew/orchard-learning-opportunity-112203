# 研学果园的实地接触机会与课程替换

`资料/演练.json` 保存本地合成的业务记录，不含个人信息及实际企业数据。各资料集的字段、单位和有效范围见[资料格式](资料格式.md)。需要 Python 3.11.2，仅使用标准库，从项目根目录运行。

查看资料包的记录数量：

```sh
python3 inspect_packet.py
```

## 班后课程证明与当天处置

```sh
python3 main.py [资料包]                   # 总览：班后证明 + 当天处置
python3 main.py [资料包] proof             # 仅班后课程证明
python3 main.py [资料包] plan [--at HH:MM] # 仅当天处置（可指定判定时刻）
python3 main.py [资料包] child L01         # 个人：通知、依据、班后证明分列
python3 main.py [资料包] merge 新到资料.json # 并入新到资料，列出证明与候补变化
```

- **计数表核对**：计数表只说恰有几人独立操作，个人记录与回单可以缩小候选
  范围、不能另外加一次。工具枚举能同时解释全部记录的情形（同一人在同一
  时段只能在一个操作位；低台需求不适用 `accessible:false` 的工位），只
  输出各情形一致的结论，不自行补齐名单；凭证不足不等于缺席。
- **分母、覆盖、重复体验**：按班别 × 可及性需求给出，另附转组后归属口径；
  顺序完成链要求同一孩子按先后独立完成全部课程目标——分选、测量各自
  覆盖人数不等于同一批孩子走完了两段。
- **当天处置**：通知按发出时刻已知的凭证核定依据；候补区分"现在就可以
  给 / 要等到确认 / 即使总座位够也无法保证"。两份候补只有依据已知凭证
  和登记的核对内容确实不会一起生效才可共用一席；按期无回单不等于否定
  答复，不能按否定分支把位置给出去。已通知的机会始终占位，新方案不能
  悄悄占掉。
- **新到资料**：回单或转组消息改变可行范围时，`merge` 列出哪些候补现在
  可以确认、哪些只能另找后续工位；开场后补到的资料只更正班后证明，不
  倒填当时的分配。

编译与测试：

```sh
python3 -m compileall -q inspect_packet.py packet.py model.py solve.py decide.py report.py main.py tests
python3 -m unittest discover -s tests -v
```

`inspect_packet.py` 只读取资料包并列出记录规模；`main.py` 给出业务分析
与处置结果；测试覆盖输入约定、情形枚举、候补处置与新到资料合并。
